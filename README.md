# BlinkIT Sales Analytics Dashboard | Power BI

An interactive Power BI dashboard built to analyze BlinkIT sales performance, customer behavior, product performance, and key business metrics.

## 📊 Project Overview

This project focuses on transforming sales data into an interactive business intelligence dashboard using Microsoft Power BI.

The dashboard provides a centralized view of important business KPIs and enables users to explore sales performance across different products, categories, outlets, and other business dimensions.

## 🎯 Objectives

- Analyze overall sales performance
- Track important business KPIs
- Identify high-performing products and categories
- Understand outlet-level performance
- Analyze customer purchasing patterns
- Compare sales across different business dimensions
- Create an interactive and easy-to-use dashboard for business decision-making

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization
- Business Intelligence

## 📌 Dashboard Features

### 🏠 Home
Provides an overview of the business with key performance indicators and navigation to different analytical sections.

### 💰 Sales Analysis
Helps analyze overall sales performance and identify trends and patterns in revenue.

### 👥 Customer Analysis
Provides insights into customer-related metrics and purchasing behavior.

### 📦 Product Analysis
Analyzes product-level performance and helps identify products contributing significantly to sales.

## 📈 Key KPIs

The dashboard focuses on business metrics such as:

- Total Sales
- Average Sales
- Number of Items
- Product Performance
- Outlet Performance
- Category Performance

## 🔍 Business Insights

The dashboard can be used to answer questions such as:

- Which products generate the highest sales?
- Which categories perform the best?
- Which outlets contribute most to overall revenue?
- What are the major sales trends?
- Which products or categories require attention?
- How can business performance be improved?
